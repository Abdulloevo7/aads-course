## Цель работы

Реализовать собственные шаблонные классы стека, очереди, дека и приоритетной очереди без использования контейнеров стандартной библиотеки. Освоить принципы LIFO и FIFO, реализацию структур на динамическом массиве, кольцевом буфере, связном списке и двоичной куче. Применить каждую структуру к практической задаче: проверке скобок, моделированию очереди, проверке палиндрома и поиску наибольших элементов.

## Теоретическая часть

**Стек** работает по принципу LIFO: последним пришёл, первым ушёл. Элементы добавляются и извлекаются только с вершины. Основные операции: `push`, `pop`, `top`, `isEmpty`, `size`.

**Очередь** работает по принципу FIFO: первым пришёл, первым ушёл. Элементы добавляются в конец и извлекаются из начала. Основные операции: `enqueue`, `dequeue`, `front`, `isEmpty`, `size`.

**Дек** — двусторонняя очередь, в которой добавлять и удалять элементы можно с обоих концов. Операции: `push_front`, `push_back`, `pop_front`, `pop_back`, `front`, `back`.

**Приоритетная очередь** хранит элементы с приоритетами, и первым извлекается элемент с наибольшим приоритетом. Её обычно строят на **двоичной куче** — почти полном двоичном дереве, в котором каждый родитель не меньше своих потомков. Дерево хранится в массиве: потомки элемента с индексом `i` имеют индексы `2i+1` и `2i+2`, а родитель индекс `i-1`, делённый на 2 с отбрасыванием остатка.

**Кольцевой буфер** — массив, в котором индексы начала и конца очереди сдвигаются по модулю ёмкости. Это позволяет не переносить элементы при каждом извлечении.

**Просеивание.** Операция `heapifyUp` поднимает новый элемент вверх, пока он больше родителя. Операция `heapifyDown` опускает элемент вниз, обменивая его с большим из потомков.

Сложность основных операций:

| Структура | Добавление | Удаление | Просмотр |
|---|---|---|---|
| Стек | O(1) амортизированно | O(1) | O(1) |
| Очередь | O(1) амортизированно | O(1) | O(1) |
| Дек | O(1) | O(1) | O(1) |
| Приоритетная очередь | O(log n) | O(log n) | O(1) |

// Стек на динамическом массиве
template <typename T>
class Stack {
private:
    T* data;
    int topIndex;
    int capacity;

    void resize() {
        int newCapacity = capacity * 2;
        T* newData = new T[newCapacity];
        for (int i = 0; i <= topIndex; i++) {
            newData[i] = data[i];
        }
        delete[] data;
        data = newData;
        capacity = newCapacity;
    }

public:
    Stack(int initialCapacity = 10) : data(nullptr), topIndex(-1), capacity(initialCapacity) {
        if (capacity < 1) {
            throw invalid_argument("Ёмкость должна быть положительной");
        }
        data = new T[capacity];
    }

    Stack(const Stack&) = delete;
    Stack& operator=(const Stack&) = delete;

    ~Stack() {
        delete[] data;
    }

    void push(const T& value) {
        if (topIndex >= capacity - 1) {
            resize();
        }
        data[++topIndex] = value;
    }

    T pop() {
        if (isEmpty()) {
            throw underflow_error("Стек пуст");
        }
        return data[topIndex--];
    }

    T top() const {
        if (isEmpty()) {
            throw underflow_error("Стек пуст");
        }
        return data[topIndex];
    }

    bool isEmpty() const { return topIndex == -1; }
    int size() const { return topIndex + 1; }
};
```

// Очередь на кольцевом буфере
template <typename T>
class Queue {
private:
    T* data;
    int frontIndex;
    int rearIndex;
    int count;
    int capacity;

    void resize() {
        int newCapacity = capacity * 2;
        T* newData = new T[newCapacity];
        for (int i = 0; i < count; i++) {
            newData[i] = data[(frontIndex + i) % capacity];
        }
        delete[] data;
        data = newData;
        frontIndex = 0;
        rearIndex = count;
        capacity = newCapacity;
    }

public:
    void enqueue(const T& value) {
        if (count >= capacity) {
            resize();
        }
        data[rearIndex] = value;
        rearIndex = (rearIndex + 1) % capacity;
        count++;
    }

    T dequeue() {
        if (isEmpty()) {
            throw underflow_error("Очередь пуста");
        }
        T value = data[frontIndex];
        frontIndex = (frontIndex + 1) % capacity;
        count--;
        return value;
    }

    T front() const {
        if (isEmpty()) {
            throw underflow_error("Очередь пуста");
        }
        return data[frontIndex];
    }
};

// Дек на двусвязном списке
template <typename T>
class Deque {
private:
    struct Node {
        T data;
        Node* prev;
        Node* next;

        Node(const T& value) : data(value), prev(nullptr), next(nullptr) {}
    };

    Node* head;
    Node* tail;
    int count;

public:
    ~Deque() {
        while (head != nullptr) {
            Node* temp = head;
            head = head->next;
            delete temp;
        }
    }

    T pop_front() {
        if (isEmpty()) {
            throw underflow_error("Дек пуст");
        }
        Node* temp = head;
        T value = temp->data;
        head = head->next;
        if (head != nullptr) {
            head->prev = nullptr;
        } else {
            tail = nullptr;
        }
        delete temp;
        count--;
        return value;
    }

    T pop_back() {
        if (isEmpty()) {
            throw underflow_error("Дек пуст");
        }
        Node* temp = tail;
        T value = temp->data;
        tail = tail->prev;
        if (tail != nullptr) {
            tail->next = nullptr;
        } else {
            head = nullptr;
        }
        delete temp;
        count--;
        return value;
    }
};

// Приоритетная очередь на двоичной куче, max-heap
template <typename T>
class PriorityQueue {
private:
    T* heap;
    int count;
    int capacity;

    void heapifyUp(int index) {
        while (index > 0) {
            int parent = (index - 1) / 2;
            if (heap[index] > heap[parent]) {
                swap(heap[index], heap[parent]);
                index = parent;
            } else {
                break;
            }
        }
    }

    void heapifyDown(int index) {
        while (true) {
            int left = 2 * index + 1;
            int right = 2 * index + 2;
            int largest = index;
            if (left < count && heap[left] > heap[largest]) {
                largest = left;
            }
            if (right < count && heap[right] > heap[largest]) {
                largest = right;
            }
            if (largest == index) {
                break;
            }
            swap(heap[index], heap[largest]);
            index = largest;
        }
    }

public:
    void push(const T& value) {
        if (count >= capacity) {
            resize();
        }
        heap[count] = value;
        heapifyUp(count);
        count++;
    }

    T pop() {
        if (isEmpty()) {
            throw underflow_error("Приоритетная очередь пуста");
        }
        T maxValue = heap[0];
        heap[0] = heap[count - 1];
        count--;
        heapifyDown(0);
        return maxValue;
    }
};
```

// Задача для стека: правильность расстановки скобок
bool checkBrackets(const string& expr) {
    Stack<char> stack;
    for (char ch : expr) {
        if (ch == '(' || ch == '[' || ch == '{') {
            stack.push(ch);
        } else if (ch == ')' || ch == ']' || ch == '}') {
            if (stack.isEmpty()) {
                return false;
            }
            char open = stack.pop();
            if ((ch == ')' && open != '(') ||
                (ch == ']' && open != '[') ||
                (ch == '}' && open != '{')) {
                return false;
            }
        }
    }
    return stack.isEmpty();
}

// Задача для очереди: модель очереди в банке с одним окном
void simulateBank(const Customer* customers, int n) {
    Queue<Customer> line(2);
    int clock = 0;
    int busyUntil = 0;
    int next = 0;
    int served = 0;
    int totalWait = 0;
    int maxWait = 0;
    int maxLine = 0;

    while (served < n) {
        while (next < n && customers[next].arrival <= clock) {
            line.enqueue(customers[next]);
            next++;
            if (line.size() > maxLine) {
                maxLine = line.size();
            }
        }
        if (clock >= busyUntil && !line.isEmpty()) {
            Customer c = line.dequeue();
            int wait = clock - c.arrival;
            busyUntil = clock + c.service;
            totalWait += wait;
            if (wait > maxWait) {
                maxWait = wait;
            }
            served++;
        }
        clock++;
    }
}

// Задача для дека: палиндром без учёта регистра и небуквенных символов
bool isPalindrome(const string& str) {
    Deque<char> dq;
    for (char ch : str) {
        if (isalnum((unsigned char)ch)) {
            dq.push_back((char)tolower((unsigned char)ch));
        }
    }
    while (dq.size() > 1) {
        char left = dq.pop_front();
        char right = dq.pop_back();
        if (left != right) {
            return false;
        }
    }
    return true;
}

void kLargest(const int* arr, int n, int k, int* result) {

### Стек

| Операция | Сложность | Обоснование |
|---|---|---|
| `push` | O(1) амортизированно, O(n) в худшем случае | Расширение массива с копированием происходит редко |
| `pop` | O(1) | Уменьшение индекса вершины |
| `top` | O(1) | Обращение по индексу |

| Операция | Сложность | Обоснование |
|---|---|---|
| `enqueue` | O(1) амортизированно, O(n) в худшем случае | Расширение буфера происходит редко |
| `dequeue` | O(1) | Сдвиг индекса начала по модулю |
| `front` | O(1) | Обращение по индексу |
| `isEmpty`, `size` | O(1) | Возврат счётчика |

### Дек

| Операция | Сложность | Обоснование |
|---|---|---|
| `push_front`, `push_back` | O(1) | Доступ к головному и хвостовому узлам |
| `pop_front`, `pop_back` | O(1) | Предыдущий узел доступен через `prev` |
| `front`, `back` | O(1) | Возврат данных крайнего узла |
| `isEmpty`, `size` | O(1) | Возврат счётчика |
| Деструктор | O(n) | Удаление каждого узла |

### Приоритетная очередь

| Операция | Сложность | Обоснование |
|---|---|---|
| `push` | O(log n) | Просеивание вверх на высоту дерева |
| `pop` | O(log n) | Просеивание вниз на высоту дерева |
| `top` | O(1) | Максимум лежит в корне |
| `isEmpty`, `size` | O(1) | Возврат счётчика |

Высота кучи из n элементов равна log₂n, поэтому каждое просеивание выполняет не более log₂n обменов. Расширение массива добавляет амортизированный вклад O(1).

## Ответы на контрольные вопросы

**1. В чём заключается принцип работы стека?**

Стек работает по принципу LIFO, то есть последним пришёл, первым ушёл. Добавление и удаление происходят только с одного конца, вершины. Пример: стопка тарелок, где берут ту, что положили последней.

**2. В чём заключается принцип работы очереди?**

Очередь работает по принципу FIFO, то есть первым пришёл, первым ушёл. Элементы добавляются в конец и извлекаются из начала. Пример: очередь в магазине.

**3. Чем дек отличается от обычной очереди?**

В очереди добавление идёт только в конец, а удаление только из начала. В деке и добавлять, и удалять можно с обоих концов. Поэтому дек можно использовать и как стек, и как очередь.

**4. Что такое приоритетная очередь? Где она применяется?**

Это структура, в которой каждый элемент имеет приоритет, и первым извлекается элемент с наибольшим приоритетом, а не самый старый. Применяется в планировщиках процессов, в алгоритме Дейкстры для поиска кратчайших путей, при сжатии по алгоритму Хаффмана, в системах обработки событий и при поиске K наибольших элементов.

**5. Как реализовать стек на основе динамического массива?**

Хранится массив, его ёмкость и индекс вершины. Операция `push` записывает элемент в следующую ячейку после вершины, а при нехватке места массив расширяется вдвое. Операция `pop` уменьшает индекс вершины. Так устроен класс `Stack` в этой работе.

**6. Как реализовать очередь на основе кольцевого буфера?**

Массив рассматривается как замкнутый. Хранятся индекс начала, индекс конца и число элементов. При добавлении элемент записывается по индексу конца, и индекс увеличивается по модулю ёмкости, при извлечении так же сдвигается индекс начала. Элементы не переносятся, поэтому обе операции выполняются за O(1). При заполнении буфер расширяется с выравниванием элементов с нулевой позиции.

**7. Почему приоритетную очередь обычно реализуют на куче?**

Куча даёт добавление и извлечение максимума за O(log n), а просмотр максимума за O(1). Отсортированный массив даёт быстрое извлечение, но вставка стоит O(n). Неупорядоченный массив даёт быструю вставку, но извлечение максимума стоит O(n). Куча занимает компромиссное и выгодное положение. Она хранится в обычном массиве без указателей.

**8. Какова сложность операций `push` и `pop` в стеке?**

Обе операции выполняются за O(1). Операция `push` на динамическом массиве имеет амортизированную сложность O(1), потому что редкое расширение с копированием O(n) распределяется между многими вставками.

**9. Какова сложность операций `enqueue` и `dequeue` в очереди?**

Операция `dequeue` выполняется за O(1). Операция `enqueue` выполняется за O(1) амортизированно, а в моменты расширения буфера за O(n). В реализации на связном списке обе операции выполняются за O(1) без амортизации.

**10. Какова сложность операций в приоритетной очереди? Почему?**

Добавление и извлечение выполняются за O(log n), просмотр максимума за O(1). Причина в том, что куча является почти полным двоичным деревом высотой log₂n. Новый элемент поднимается вверх, а корень после извлечения опускается вниз, и каждый путь не длиннее высоты дерева.

**11. Как проверить правильность расстановки скобок с помощью стека?**

Выражение просматривается слева направо. Каждая открывающая скобка кладётся в стек. При встрече закрывающей скобки из стека извлекается верхняя, и она должна быть парной. Если стек пуст или скобка не парная, расстановка неверна. В конце стек обязан быть пустым, иначе остались незакрытые скобки. Сложность O(n).

**12. Как реализовать очередь на двух стеках? Какова сложность?**

Используются входной и выходной стеки. Операция `enqueue` кладёт элемент во входной стек. При `dequeue`, если выходной стек пуст, все элементы переносятся из входного в выходной, при этом порядок разворачивается, и верхний элемент выходного стека берётся как начало очереди. Каждый элемент переносится не более одного раза. Поэтому амортизированная сложность обеих операций O(1), а в худшем случае отдельный `dequeue` стоит O(n).

**13. Как реализовать дек на основе двусвязного списка?**

Список хранит указатели на голову и хвост, а каждый узел знает предыдущего и следующего соседей. Операции `push_front` и `pop_front` работают с головой, `push_back` и `pop_back` с хвостом. Все четыре операции выполняются за O(1). Так реализован класс `Deque` в этой работе.

**14. Как реализовать дек на основе кольцевого буфера?**

Хранятся массив, индекс начала и число элементов. Добавление в конец пишет в позицию начала плюс число элементов по модулю ёмкости. Добавление в начало сдвигает индекс начала назад по модулю ёмкости и пишет туда. Удаление с любого конца обновляет начало или счётчик. Все операции O(1) амортизированно, но расход памяти меньше, чем у списка, и обращение по индексу тоже занимает O(1).

**15. Как реализовать стек с поддержкой получения минимума за O(1)?**

Рядом с основным стеком ведётся вспомогательный стек минимумов. При `push` значение кладётся в основной стек, а во вспомогательный кладётся меньшее из нового значения и текущего минимума. При `pop` извлекаются элементы из обоих стеков. Текущий минимум всегда лежит на вершине вспомогательного стека, и `getMin` выполняется за O(1). Расход памяти увеличивается вдвое.

## Вывод

В ходе лабораторной работы без использования контейнеров стандартной библиотеки реализованы четыре структуры данных: стек на динамическом массиве, очередь на кольцевом буфере, дек на двусвязном списке и приоритетная очередь на двоичной куче. Каждая структура обрабатывает попытку извлечь элемент из пустой структуры исключением, а память освобождается в деструкторах. Копирование запрещено для защиты от двойного освобождения. Корректность проверена на граничных случаях, включая расширение массива, переход индекса через границу кольцевого буфера и пустые структуры. Программа проверена инструментами контроля памяти, утечек и ошибок доступа нет. Решены задачи варианта: проверка скобок на стеке, модель очереди в банке, проверка палиндрома на деке и поиск K наибольших элементов на куче. Освоены принципы LIFO и FIFO, а также оценка сложности операций, включая амортизированную для расширяемых массивов.
