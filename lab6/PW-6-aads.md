## Теоретическая часть

**Рекурсия** — метод, при котором функция вызывает саму себя для решения подзадач меньшего размера. Рекурсивная функция состоит из двух частей. **Базовый случай** задаёт условие остановки, например `n <= 1` для факториала. **Шаг рекурсии** вызывает функцию с меньшим параметром. Без базового случая рекурсия бесконечна и приводит к переполнению стека вызовов.

**Виды рекурсии.** При прямой рекурсии функция вызывает сама себя. При косвенной функция A вызывает B, а B вызывает A. Рекурсия называется хвостовой, если рекурсивный вызов является последней операцией функции. Такую рекурсию компилятор может заменить циклом.

**Стек вызовов.** Каждый рекурсивный вызов занимает память в стеке, поэтому глубина рекурсии определяет расход памяти. Для рекурсивного факториала он составляет O(n).

**Простые сортировки** имеют квадратичную сложность в среднем и худшем случае:

| Алгоритм | Лучший случай | Средний случай | Худший случай | Память | Устойчивость |
|---|---|---|---|---|---|
| Пузырьковая | O(n) | O(n²) | O(n²) | O(1) | Да |
| Вставками | O(n) | O(n²) | O(n²) | O(1) | Да |
| Выбором | O(n²) | O(n²) | O(n²) | O(1) | Нет |

**Пузырьковая сортировка** многократно сравнивает соседние элементы и меняет их местами, из-за чего наибольший элемент «всплывает» в конец. С флагом обмена она останавливается на уже упорядоченном массиве за один проход.

**Сортировка вставками** берёт очередной элемент и вставляет его на нужное место в уже отсортированной левой части, сдвигая большие элементы вправо.

**Сортировка выбором** на каждом шаге находит минимум в неотсортированной части и ставит его на текущую позицию. Число сравнений не зависит от порядка данных.

**Устойчивой** называется сортировка, которая сохраняет относительный порядок элементов с равными ключами.

```cpp
long long factorial(int n) {
    if (n < 0 || n > 20) {
        throw out_of_range("Факториал определён для n от 0 до 20");
    }
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

long long factorialIter(int n) {
    if (n < 0 || n > 20) {
        throw out_of_range("Факториал определён для n от 0 до 20");
    }
    long long result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}
```

```cpp
    if (n < 0) {
        throw invalid_argument("Показатель степени должен быть неотрицательным");
    }
    if (n == 0) {
        return 1;
    }
    return a * power(a, n - 1);
}

long long powerFast(long long a, int n) {
    if (n < 0) {
        throw invalid_argument("Показатель степени должен быть неотрицательным");
    }
    if (n == 0) {
        return 1;
    }
    long long half = powerFast(a, n / 2);
    if (n % 2 == 0) {
        return half * half;
    }
    return half * half * a;
}
```

```cpp
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) {
            break;
        }
    }
}

void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        if (minIndex != i) {
            swap(arr[i], arr[minIndex]);
        }
    }
}
```

## Ответы на контрольные вопросы

**1. Что такое рекурсия? Из каких компонентов состоит рекурсивная функция?**

Рекурсия — приём, при котором функция вызывает саму себя для решения подзадачи меньшего размера. Рекурсивная функция состоит из базового случая, который останавливает рекурсию, и шага рекурсии, который вызывает функцию с уменьшенными параметрами.

**2. Что такое базовый случай рекурсии? Почему он важен?**

Это условие, при котором функция возвращает результат без дальнейших вызовов, например `n <= 1` для факториала. Без него рекурсия бесконечна, стек вызовов переполняется и программа аварийно завершается. Кроме того, шаги рекурсии должны приближать параметр к базовому случаю.

**3. Чем отличается прямая рекурсия от косвенной?**

При прямой функция вызывает сама себя, как `factorial` вызывает `factorial`. При косвенной функция A вызывает B, а B снова вызывает A. Пример: взаимно рекурсивные функции `even` и `odd`, проверяющие чётность числа.

**4. Что такое хвостовая рекурсия? В чём её преимущество?**

Это рекурсия, в которой рекурсивный вызов является последней операцией функции, а результат передаётся через дополнительный параметр, аккумулятор. Преимущество в том, что компилятор может заменить такие вызовы циклом, и память стека не растёт. Обычный факториал `n * factorial(n - 1)` хвостовым не является, потому что после вызова ещё выполняется умножение.

**5. Какова временная сложность рекурсивного вычисления чисел Фибоначчи? Почему?**

Экспоненциальная, O(2ⁿ), точнее порядка φⁿ. Каждый вызов порождает два новых, а одни и те же значения вычисляются многократно. Например, при вычислении F(30) выполняется 2 692 537 вызовов, как показал эксперимент.

**6. Как можно оптимизировать рекурсивное вычисление Фибоначчи?**

Запоминанием результатов, то есть мемоизацией: вычисленные значения сохраняются в массив, и повторный вызов берёт готовое значение. Тогда каждое значение вычисляется один раз, а сложность падает до O(n). Другой вариант — итеративное вычисление с двумя переменными за O(n) и O(1) по памяти.

**7. В чём отличие рекурсивной реализации от итеративной?**

Рекурсивная версия выражает решение через решение подзадач и часто короче и ближе к математическому определению. Итеративная использует циклы и обычно быстрее и экономнее по памяти, так как нет накладных расходов на вызовы и нет риска переполнения стека. В эксперименте итеративные числа Фибоначчи быстрее рекурсивных на порядки.

**8. Какова сложность пузырьковой сортировки? Когда она становится O(n)?**

В среднем и худшем случаях O(n²). Она становится O(n) на уже отсортированном массиве при использовании флага обмена: первый проход не находит ни одного обмена, и алгоритм останавливается. В эксперименте на отсортированных данных она заняла 5 мкс.

**9. Чем сортировка вставками отличается от сортировки выбором?**

Вставки берут очередной элемент и вставляют его в уже отсортированную левую часть, число операций зависит от порядка данных, и для упорядоченных данных сортировка работает за O(n). Выбор ищет минимум в оставшейся части и ставит его на место, делает всегда около n²/2 сравнений, зато не более n − 1 обменов.

**10. Какая из простых сортировок является устойчивой? Что это значит?**

Устойчивыми являются пузырьковая сортировка и сортировка вставками. Устойчивость означает, что элементы с равными ключами сохраняют исходный относительный порядок. Обычная сортировка выбором неустойчива, потому что обмен далёких элементов может переставить равные значения.

**11. Какая из простых сортировок работает лучше на почти отсортированных данных?**

Сортировка вставками: ей нужно лишь немного сдвигов, и время приближается к O(n). В эксперименте на почти отсортированном массиве из 10 000 элементов она заняла 378 мкс против 39 316 мкс у пузырьковой и 129 126 мкс у выбора.

**12. Как реализовать пузырьковую сортировку с оптимизацией?**

Добавить флаг обмена: если за полный проход не произошло ни одного обмена, массив уже упорядочен и цикл прерывается. Дополнительно после каждого прохода внутренний цикл сокращается на один элемент, так как наибольший элемент уже стоит на месте. Так сделано в листинге 5.

**13. Что такое рекурсивный поиск с возвратом?**

Это метод перебора вариантов, при котором алгоритм делает выбор, рекурсивно продолжает поиск, а при тупике отменяет последний выбор и пробует другой. Применяется для лабиринтов, задачи о ферзях, генерации перестановок и подмножеств.

**14. Как рекурсивно обойти лабиринт?**

Из текущей клетки функция по очереди пробует перейти в четыре соседние клетки. Клетка отвергается, если она вне границ, является стеной или уже посещена. Если достигнут финиш, возвращается успех, и клетки пути помечаются при возврате. Если ни одно направление не привело к финишу, функция возвращает неудачу, и вызывающая функция пробует другое направление.

**15. Какова сложность Ханойских башен? Сколько ходов нужно для перемещения n дисков?**

Для перемещения n дисков необходимо 2ⁿ − 1 ходов, поэтому сложность O(2ⁿ). Рекурсия переносит n − 1 дисков на вспомогательный стержень, затем один диск, затем снова n − 1 дисков. Число ходов T удовлетворяет соотношению T(n) = 2T(n − 1) + 1. Для трёх дисков нужно 7 ходов, для десяти 1023.
